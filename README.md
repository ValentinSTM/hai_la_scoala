# 🎒 Hai la școală! · Klar til skole!

Aplicație de pregătire pentru 0. klasse (børnehaveklasse), în **română și daneză**, pentru un copil care încă nu citește: totul e citit cu voce tare.
Forberedelse til 0. klasse på **rumænsk og dansk** for et barn, der ikke kan læse endnu: alt bliver læst højt.

**▶ Deschide / Åbn:** https://valentinstm.github.io/hai_la_scoala/

## Pe telefon (Samsung / Android)
1. Deschide linkul în Chrome.
2. Meniu ⋮ → **Adaugă pe ecranul de pornire / Instalează aplicația**.
3. Se deschide pe tot ecranul, ca o aplicație, și merge și fără internet.

Pentru citirea cu voce trebuie instalate pe telefon vocile **Română** și **Dansk** (Setări → Gestionare generală → Limbă → Ieșire text în vorbire → Google → ⚙️ → Instalare date vocale). Testul vocii e în *Pentru părinți*.

Progresul se salvează pe telefonul folosit.

## Ce conține
- 🏫 **Ziua mea la școală**: o poveste cu imagini despre o zi în 0. klasse (rundkreds, frikvarter, madpakke, toaleta, SFO), urmată de un joc de pus în ordine.
- 🎒 **Ghiozdanul**: ce luăm la școală, cu cuvintele daneze.
- 🤔 **Ce faci dacă…?**: toaleta, dorul de părinți, „nu înțeleg”, conflicte, rătăcire, furie.
- 🗣️ **Cuvinte magice**: fraze daneze pentru prima zi („Må jeg gå på toilettet?”, „Kan du hjælpe mig?”, „Stop, det kan jeg ikke lide!”).
- 🔤 **Litere** (începe cu litera din numele lui) și 🔢 **Numere** (numărat, forme, modele).
- 😊 **Emoții** și 🎈 **respirație cu balonul**.
- 📒 **Album** cu abțibilduri primite după fiecare rundă.

## Adaptări pentru atenție
Runde scurte (2–3 minute), recompensă imediată, pauze de mișcare, fără penalizări (după a doua încercare răspunsul corect strălucește), chemare blândă înapoi dacă se pierde, „Misiunea de azi” aleasă automat, limită zilnică de runde reglabilă.

Fișiere: `index.html` (toată aplicația), `manifest.json`, `sw.js` (funcționare offline), `icon*.png/svg`.
